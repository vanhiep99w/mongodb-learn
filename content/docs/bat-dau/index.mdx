## Phạm vi dự kiến

Cài đặt môi trường và thực hiện các thao tác MongoDB đầu tiên.

## Các bài trong nhóm

- [Cài đặt MongoDB local](./cai-dat-local) — Cài MongoDB Community Edition trên các hệ điều hành phổ biến và kiểm tra dịch vụ.
- [Bắt đầu với MongoDB Atlas](./mongodb-atlas) — Tạo cluster Atlas, người dùng, network access và lấy connection string.
- [Làm quen với mongosh](./mongosh-co-ban) — Kết nối database và sử dụng các lệnh trợ giúp, điều hướng trong MongoDB Shell.
- [Làm quen với MongoDB Compass](./mongodb-compass) — Kết nối, duyệt collection và thao tác dữ liệu bằng giao diện đồ họa.
- [CRUD đầu tiên](./crud-dau-tien) — Tạo database, collection và chạy chuỗi thao tác create, read, update, delete tối thiểu.
